# Imágenes del experimento MMP-9

Fuente: results/main/metrics.csv. Generador: mmp9/plots.py.

Las matrices de conteos son medias de 100 particiones (183 moléculas por prueba), por eso tienen decimales. No representan 18.300 moléculas distintas. Las matrices porcentuales se normalizan por clase real dentro de cada repetición y luego se promedian. Filas: clase real; columnas: predicción; clase positiva: activa.

Las barras muestran media ± desviación estándar muestral; no son intervalos de confianza. Las repeticiones comparten moléculas y no son independientes.
